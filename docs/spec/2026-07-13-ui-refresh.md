日付: 2026-07-13 / 対象プロジェクト: Levely

- ステータス: 凍結（ユーザー承認済み・2026-07-13 最終確定・実装未着手）
- 作業ブランチ: `feature/levely-ui-refresh-plan` から各テーマブランチを派生
- 性格: **本件は機能追加ではなく、原則として既存挙動を維持した視覚刷新である。** アプリの挙動・データ・ルーティング・保存フローは一切変えない

## 目的（なぜ作るか）

学習記録アプリ Levely の UI を「夜ふかしの書斎」コンセプトに刷新する。
冷たい紺の夜空 × 真鍮・金の灯りという色温度のコントラストで、静かで夜更かししたくなる空気を作り、
たき火（継続）とフクロウ（相棒）で「記録を続けたくなる」動機づけを演出する。
可読性・操作性は現行を維持し、装飾は枠・余白・光源にだけ住まわせる。

## 仕様（何がどう動くか）

### 1. コンセプトと設計原則

- コンセプト名: **夜ふかしの書斎**（キーワード: 夜の窓辺 / 真鍮の窓枠 / 羊皮紙の文字 / たき火の火の粉 / 相棒のフクロウ / 夜明け前の地平線）
- 原則1 色温度のコントラスト — 背景は冷たい紺、枠と強調は暖かい真鍮・金
- 原則2 盤面は静かに、灯りだけが生きている — 常時動くのは火・星・フクロウ（瞬き）・今日カーソルのみ
- 原則3 実用第一 — 文字色・情報構造・操作フローは現行維持。本文テキストに装飾を載せない

### 3. 共通ルール

- **枠**: `.rpg-window` = 外周黒2px → 真鍮2px → 内側黒1px(inset) の多層＋四隅に6px角ピクセル（`::after` に4方向 `linear-gradient` を no-repeat 配置）。多層枠は大枠とモーダルのみ、内部は1px細枠、入れ子は2段まで
- **角丸**: 原則0〜2px。円形要素（`day-number`、メダル、ドット）は角形化。例外はログインの月のみ
- **影**: ぼかしゼロのハードシャドウ。ぼかし（グロー）は光源3箇所（たき火・月・アクティブクエスト）だけ、alpha 0.2以下
- **ボタン**: 役割3色制 — ミント=進む/保存（primary、1画面1つ）／透明＋真鍮枠=中立／赤=危険。全ボタン `:active` で `translate(2px,2px)`＋影消しの押し込み。金はボタンに使わない
- **チップ**: カテゴリ=カテゴリ色ベタ＋黒枠、時間=`--rpg-panel-lift` 面＋細枠
- **入力欄**: 背景 `#0a0e1a`、2px真鍮枠、focus金＋`focus-visible` アウトライン。高さ・レイアウト不変
- **文字**: DotGothic16 のみ（追加フォントなし）。数字強調（streak・EXP）は `--candle`＋`text-shadow: 2px 2px 0` 黒。見出しは字間 0.06〜0.1em。最小フォント 0.65rem（現 0.55rem 箇所を引き上げ）
- **アイコン・キャラクター**: フクロウ・たき火・絵文字置換アイコンを含め、絵はすべて `app/views/shared/icons/` 配下のインラインSVGパーシャル（1px `<rect>`＋`shape-rendering="crispEdges"`、既存9種と同じ作法）を一次ソースとする。**文字とCSSで成立する箇所（気づきラベル・「まとめ」ラベル・空状態など）にはアイコンを追加しない**
- **CSS 疑似要素の用途制限**: 疑似要素で描いてよいのは ①たき火背後の光 ②枠の四隅の角ピクセル ③単純な点・線・背景装飾（凡例マーカー・区切り線・星など）のみ。アイコン・キャラクターを疑似要素で描かない
- **画像素材の禁止**: data URI・Base64 埋め込み画像・外部画像・画像生成素材はすべて使用禁止。絵はインラインSVGパーシャルと上記範囲の CSS 表現のみで賄う
- **アニメーション総量規制**: **同一画面で常時ループ最大6系統**。数え方: 同一目的・同一 keyframes 群で動く要素の集合を1系統と数える（例: 火の粉2粒=1系統、同一層内の星すべて=1系統、炎の3フレーム切替=1系統）。単発演出（メダルフラッシュ・モーダルポップ・押し込み）は数えない。全て transform / opacity のみ。box-shadow・filter・gradient の keyframe 禁止（グローは静的 gradient の opacity 脈動）

| 画面 | 常時ループの内訳 | 計 |
|---|---|---|
| メイン（点火時） | 炎フレーム / 火の粉 / グロー脈動 / 星twinkle / 今日カーソル点滅 / フクロウ瞬き | 6 |
| メイン（消灯時） | 煙 / 星twinkle / 今日カーソル点滅 / フクロウ瞬き | 4 |
| ログイン | 星twinkle第1層 / 星twinkle第2層 / 星漂い / 流れ星 / ▶点滅 / フクロウ瞬き | 6 |

※フクロウ瞬きは Stimulus のクラス切替で駆動（CSS の周期 keyframes ではない）が、画面上の動きとして1系統に数える

- **innerHTML 方針（重要）**: JS が `innerHTML` で描画する領域（日報パネル・クエストティア・要約カード）は**既存マークアップと既存クラスへの CSS 適用のみ**で刷新し、JS のテンプレート文字列は原則変更しない。唯一の例外は PR7 の 🔒 絵文字置換で、ERB 側で `_lock` パーシャルを描画した `<template>` を `monthly_goal_controller.js` が既存 `rowTemplate`（`monthlies/show.html.erb`）と同じ `cloneNode` 作法で複製する。**SVG を JS 文字列に直書きしない。`<template>` 複製の利用はこの1箇所に限定する**
  - プラーク=既存 `.panel-edit-btn` / `.modal-header` の再スタイル、チップ=既存 `.panel-item-category` / `.panel-item-duration` の再スタイルで、マークアップ変更なしに実現する
- **reduced-motion**: `prefers-reduced-motion: reduce` で ambient 系 keyframes を一括停止（CSS media query）。炎はフレーム1で静止表示（火は消えない）。Stimulus 側も `matchMedia` で瞬きを無効化（静止表示）。**静止状態でもすべての情報・状態（点火/消灯・日数・今日・記録有無・クエスト状態）が判別できること**
- **アクセシビリティ**: 装飾 SVG は `aria-hidden="true"`・`pointer-events: none`。日数・状態は必ずテキスト併記。コントラスト: 本文≈10:1超、muted≥4.5:1、真鍮枠≈3:1。点滅は約1Hz以下
- **パフォーマンス**: 星は1要素 box-shadow 方式。画像ファイル追加ゼロ・フォント追加ゼロ・HTTPリクエスト増ゼロ

### 5. たき火の仕様

責務分担（確定）:
- **薪・炎・火の粉・煙**: インラインSVG（新規パーシャル `shared/icons/_campfire.html.erb`、16×16 viewBox、`shape-rendering="crispEdges"`）
- **背後の光（グロー）**: 親HTML要素の CSS 疑似要素（`.campfire::before` に静的 radial-gradient、opacity のみ3.4sで脈動）
- **アニメーション**: すべて CSS（`ambient.css`）。炎=3フレームの opacity 切替 0.8s／火の粉=translate+opacity `steps(4)` 2粒／煙=消灯時のみ `steps(6)` 上昇
- **状態判定とクラス付与**: ERB（`monthlies/show.html.erb`）。`@streak_count` と `@today_log&.recorded?` のみ使用（コントローラ変更なし。Stimulus 不使用）

状態と文言（承認済み・確定）:

| 状態 | 条件 | 見た目 | メイン行 | サブ行 |
|---|---|---|---|---|
| 消灯 | `streak == 0`（初回利用も同じ。最終記録日の追加判定はしない） | 薪のみ彩度落とし＋煙・グローなし | たき火は静かに消えています | 今日の記録から、また火を灯そう |
| 火種 | streak 1〜6 | 小さな炎＋火の粉1粒 | たき火が N 日燃えつづけています | ↓のいずれか |
| 通常火 | streak 7〜29 | 3フレームの炎＋火の粉2粒＋グロー | 同上 | 同上 |
| 大火 | streak 30以上 | 炎1段高く＋火の粉が金色 | 同上 | 同上 |

- サブ行（streak≥1）: 今日未記録=「今日の薪をくべて、火をつなごう」／今日記録済み=「今日の薪もくべました。火は静かに燃えています」
- 消灯文言は指定の1文を、レイアウト固定のためメイン行＋サブ行に分割して表示する（文字列は指定どおり）
- **レイアウトシフト禁止（確定）**: `.campfire` の外寸は全状態で固定（56×56px）。SVG は常に同一 viewBox・同一サイズで、状態変化は内部グループの表示切替のみ。グロー疑似要素の inset も固定。テキストは常にメイン行＋サブ行の2行構造で高さ不変
- 大きさの状態は `campfire--out / --s / --m / --l` クラスで表現（`transform: scale` は使わない。ピクセルが割れるため表示グループの切替で実現）
- reduced-motion: 全 keyframes 停止、炎はフレーム1で静止（消灯扱いにしない。点火/消灯・大きさ段階は静止状態でも判別できる）

### 6. フクロウの仕様

- 配置: ①ログイン=タイトル上・中央（約32px） ②メイン=「今日の記録」パネル枠の右上にとまる（absolute配置）。この2箇所のみ
- 役割: 装飾的な相棒（承認済み）。ナビゲーションには使わない。`pointer-events: none`・`aria-hidden="true"`
- 実装: 新規パーシャル `shared/icons/_owl.html.erb`（11×12 グリッドのインラインSVG。まぶた=体色の rect 2枚を `.owl-lids` グループで内蔵）
- **動きは「Stimulus によるランダムな両目の瞬き」のみ（確定）**。CSS の周期瞬きアニメーションは作らない
  - 新規 `owl_controller.js` の**責務は瞬き制御だけ**: 乱数スケジューラ（4〜8秒間隔・140ms閉眼・30%で二度瞬き）で `.owl--blink` クラスを付け外しし、まぶた（`.owl-lids`）の表示を切り替える。`matchMedia("(prefers-reduced-motion: reduce)")` の判定と `disconnect()` でのタイマー解除もこのコントローラが行う
  - JavaScript 無効時および reduced-motion 時は静止表示（目を開いた状態。情報の欠落なし）
  - → 制御主体が Stimulus の1系統だけになり、CSS との二重制御は構造的に起きない
- **ユーザー操作への反応は入れない（最終判断で不採用）**: 保存成功イベント・保存後フラグ・Web Storage の類は一切追加しない。保存リアクションは、将来保存フロー自体を見直す場合に再検討する
- スマホ: メインは `max-width: 800px` で非表示。ログインは表示維持
- 人型アイコンとの分担: アカウントボタンは人型ピクセルアイコンを品質調整して継続使用。フクロウは相棒専用

### 8. 境界・異常系

- streak=0（初回利用含む）: 消灯表示＋消灯文言。最終記録日の追加判定はしない（初期実装の確定仕様）
- 保存成功: 既存挙動を完全維持（モーダルが閉じ、Turbo の再訪問でカレンダー・パネルが最新化される。演出・フラグ・イベントは一切挟まない）
- JS 無効: フクロウは静止表示（開眼のまま）、`/` ショートカットは無効だがチップクリックで開く、たき火は CSS のみで完結して動き続ける
- reduced-motion: §3・§5・§6 のとおり全停止（情報は静止状態で全て読める）
- 保存失敗・通信失敗・楽観ロック競合: 既存文言・既存挙動を完全維持（ステータスの赤枠スタイル化のみ）
- 画面幅 ≤800px: メインのフクロウ非表示。≤600px: 星第2層非表示・カレンダーマーク5px。既存ブレークポイント（container 700px / media 600・800・1100px）は変更しない

## 決定済みの分かれ道（決定内容と理由）

| 分かれ道 | 決定 | 理由 |
|---|---|---|
| 配色の軸 | 紺ベース＋真鍮/金の灯り（紫全面は不採用） | 色温度コントラストが世界観の核。紫全面は彩度が上がり長時間で疲れる |
| 枠の暖色化の手法 | `--rpg-border` の値差し替え | クラス名不変で JS 生成 DOM と不整合を起こさない最小差分 |
| フォント | DotGothic16 単独継続（Press Start 2P 不採用） | 外部アセット追加・可読性低下を回避。字間とサイズで階層を作る |
| primary ボタン色 | ミント（金は強調専用に格上げ） | 現行は金が強調とアクションで両義的だった |
| アニメ総量 | 同一画面で常時ループ最大6系統（数え方は §3 で定義） | 学習記録アプリとして視線を奪わない上限（ユーザー指示で画面単位・数え方を明文化） |
| たき火の責務 | SVG=薪炎火の粉煙 / 親疑似要素=光 / CSS=動き / ERB=状態 | ユーザー指示で確定。Stimulus 不要になり最軽量 |
| たき火の外寸 | 全状態で固定（グループ切替のみ） | レイアウトシフト禁止（ユーザー指示） |
| ストリーク文言 | §5・§7 の4パターンで確定 | ユーザー指定の文言をそのまま採用（消灯文は2行に分割表示） |
| フクロウの動き | Stimulus によるランダムな両目の瞬きのみ。JS 無効・reduced-motion 時は静止表示 | 二重制御の余地を構造的になくす（ユーザー最終判断） |
| フクロウの役割 | 装飾のみ・ナビ不使用・クリック不可 | 押せそうで押せない要素は操作性を壊す |
| 保存リアクション（ホップ等） | 不採用。sessionStorage・保存成功イベント・保存後フラグを追加しない | 保存フローに状態を持ち込まない（ユーザー最終判断）。将来、保存フロー自体を見直す場合に再検討 |
| 「✓ 保存済み」表示 | スコープ外で確定（issue 化もしない） | 保存成功は即閉じ＋Turbo 再訪問という既存挙動を変えないため（ユーザー最終判断） |
| アカウントアイコン | 人型ピクセルを品質調整して維持（LVバッジ撤回） | ユーザー指示。フクロウ=相棒/人型=自分の分担は維持 |
| innerHTML 領域 | 既存マークアップ＋既存クラスへの CSS 適用のみ。JS テンプレート変更は PR7 の 🔒 置換1点だけ | 二重管理の同期漏れリスクを最小化（ユーザー指示） |
| 羽根ペン・薪の小アイコン | 不採用（気づき・「まとめ」・空状態は文字とCSSのみで成立させる） | ERB と JS の連携構造を不必要に複雑化しない（ユーザー最終判断） |
| `<template>` 複製の適用範囲 | PR7 の 🔒 置換のみ（JS生成DOMにSVGが不可欠な唯一の箇所） | 必要最小限に限定（ユーザー最終判断）。作法は既存 `rowTemplate` と同一 |
| PR 運用 | 1テーマ1PR・コミット数自由・Squash マージ | レビュー単位を保ちつつ作業コミットを縛らない（ユーザー指示） |
| カレンダー凡例の基準 | 現行の分数ベース維持（insights 基準は別issue） | コントローラのデータ変更が必要になり「見た目のみ」の原則を破るため |
| 流れ星 | ログインのみ | 作業画面で視線を奪う動きは排除 |
| 絵文字置換 | 採用するが最終段（PR7）。👑=既存 `_crown` 流用・💡=`_bulb` 新規・🔒=`_lock` 新規 | ユーザー指示。JS 文字列変更を伴うため独立テーマに隔離 |
